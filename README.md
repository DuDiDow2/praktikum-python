# Praktikum Python - IDE, Virtual Environment, dan Git

## Deskripsi

Proyek latihan Mata Kuliah Pemrograman Berorientasi Objek. Berisi program
`halo.py` (sapaan, input tahun lahir, dan perkiraan usia) serta `tampil.py`
(menampilkan tabel dengan paket `rich`).

## Membuat dan Mengaktifkan Virtual Environment

Windows:

```bash
py -m venv .venv
.venv\Scripts\Activate.ps1
```

## Menginstal Dependensi

```bash
pip install -r requirements.txt
```

## Menjalankan Program

```bash
python halo.py
python tampil.py
```
